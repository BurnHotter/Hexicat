# Security Policy

## Supported Versions

Hexicat is unlikely to receive rolling version updates. The most recent version will always be listed in the README.md file,
and any known vulnerabilities (along with the version they were found in) will be documented below.

## Reporting a Vulnerability

Please route any issues based on whether they are a bug or a security vulnerability.

For basic bugs and broken or missing functionality, create an Issue describing what is broken or missing.

For genuine security vulnerabilities (privilege escalation, data leakage, etc.), DO NOT HESITATE TO LET ME KNOW!
Send me an email at mewpowa55@gmail.com describing the vulnerability you found 
along with any proof-of-concept exploit scripts or indicators of compromise related to this vulnerability.
